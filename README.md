# 🧠 Vibe Coding Lab

> Experimentos de desenvolvimento assistido por IA, combinando Vibe Coding com fundamentos de engenharia de software.

Este repositório reúne diferentes aplicações desenvolvidas durante meus estudos para explorar como ferramentas de IA podem acelerar o desenvolvimento de software sem abrir mão de **arquitetura, segurança, regras de negócio, testes e qualidade de código**.

Sou estudante de **Desenvolvimento de Sistemas no SENAI** e desenvolvedor em formação. Já desenvolvo aplicações utilizando diferentes tecnologias e este laboratório representa uma nova etapa: entender como incorporar IA ao meu processo de desenvolvimento.

## 🤖 Meu uso de IA

A IA pode participar de diferentes etapas do desenvolvimento:

- Brainstorming e definição de funcionalidades
- Arquitetura e estrutura inicial
- Geração e explicação de código
- Refatoração
- Documentação
- Testes
- Debugging
- Revisão de código

A utilização de IA não significa aceitar automaticamente o código gerado. **As decisões sobre regras de negócio, arquitetura, segurança e comportamento das aplicações são revisadas e validadas por mim.**

> **Vibe Coding não significa deixar a IA programar sozinha. Significa explorar uma nova forma de desenvolver software.**

## 🧪 AI Notes

Quando relevante, os projetos também podem possuir um `AI_NOTES.md`, documentando como a IA foi utilizada durante o desenvolvimento.

Esse arquivo pode registrar:

- O que foi solicitado à IA
- Código ou estruturas inicialmente gerados
- Alterações feitas posteriormente
- Problemas encontrados no código gerado
- Decisões técnicas tomadas
- O que foi aprendido durante o desenvolvimento

A ideia é tornar o processo de Vibe Coding **transparente e rastreável**, e não apenas apresentar o resultado final.

## 🎯 Objetivo

Este laboratório serve como espaço para experimentar diferentes arquiteturas, tecnologias e abordagens de desenvolvimento assistido por IA.

Os projetos podem variar bastante em complexidade, mas todos seguem a mesma proposta:

**usar IA como ferramenta de produtividade sem abandonar os fundamentos de desenvolvimento de software.**
